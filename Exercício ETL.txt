Esse dataset está PERFEITO pra ETL porque tem:

❌ Nome nulo
❌ Nome em minúsculo (padronização)
❌ Email inválido (sem @)
❌ Idade negativa
❌ Cidade vazia ou nula
❌ Data inválida
❌ Dados duplicados


🔹 1. Extract (Extração)
📌 Ler CSV com Python
import pandas as pd

df = pd.read_csv("dataset_etl_realista.csv")
print(df.head())


🔹 2. Transform (Transformação)
📌 Limpeza de dados
# remover duplicados
df = df.drop_duplicates()

# remover nomes nulos
df = df.dropna(subset=["name"])

# padronizar nomes (primeira letra maiúscula)
df["name"] = df["name"].str.title()

# remover emails inválidos
df = df[df["email"].str.contains("@", na=False)]

# remover idades inválidas
df = df[df["age"] > 0]

# preencher cidade vazia
df["city"] = df["city"].fillna("Não informado")

# corrigir datas inválidas
df["signup_date"] = pd.to_datetime(df["signup_date"], errors="coerce")
df = df.dropna(subset=["signup_date"])


🔹 3. Load (Carga)
📌 Criar tabela no PostgreSQL
CREATE TABLE clientes_etl (
    id INT,
    name TEXT,
    email TEXT,
    age INT,
    city TEXT,
    signup_date DATE
);


📌 Inserir dados com Python
from sqlalchemy import create_engine

engine = create_engine("postgresql://usuario:senha@localhost:5432/seubanco")

df.to_sql("clientes_etl", engine, if_exists="replace", index=False)
