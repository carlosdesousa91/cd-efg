Sua equipe foi contratada para analisar uma vaga de **Assistente de Gestão em Dados / Analista de Dados Jr.** em uma empresa de médio porte.

Use a descrição abaixo **ou** traga uma vaga real impressa/da internet (com autorização do professor).

---

**Vaga — Assistente de Gestão em Dados**

*Requisitos:*
- Ensino médio técnico em curso da área de TI ou dados (cursando ou concluído)
- Conhecimento básico em **SQL** e bancos de dados relacionais
- Noções de **Python** para tratamento de dados
- Capacidade de **limpar e organizar** bases de planilhas e CSV
- Experiência ou interesse em **dashboards** (Power BI ou similar)
- Boa **comunicação** para apresentar indicadores à equipe de negócios
- Organização e **documentação** de processos
- Desejável: inglês para leitura técnica

*Atividades:*
- Apoiar a criação de relatórios e painéis de indicadores
- Validar qualidade de dados antes de cargas no banco
- Executar consultas SQL para extração de informações

## Atividade 4 — Associação: situação × habilidade (individual)

**Tempo sugerido:** 10 minutos  
**Objetivo:** Diferenciar habilidades técnicas e comportamentais em situações reais.

**Instrução:** Para cada item, marque **uma** letra (A, B, C ou D) correspondente à habilidade **mais central** para resolver a situação.

**Opções:**

- **A)** SQL e consultas a banco de dados  
- **B)** Limpeza e qualidade de dados  
- **C)** Visualização / dashboards (BI)  
- **D)** Comunicação e storytelling com dados  
- **E)** Análise exploratória (EDA) / estatística descritiva  
- **F)** Empreendedorismo / visão de negócio  
- **G)** Ética e privacidade de dados (LGPD)
